# Astrology Chatbot

A beautiful astrology chatbot built with Streamlit and Google Gemini AI that provides personalized zodiac readings, horoscopes, and cosmic guidance.

## Features

- 🔮 **Zodiac Sign Readings**: Get detailed insights about your zodiac sign
- 📅 **Daily Horoscopes**: Personalized daily predictions
- 💫 **Birth Chart Analysis**: Ask about planetary positions and their meanings
- ❤️ **Compatibility Analysis**: Check zodiac compatibility
- 🌟 **Cosmic Guidance**: Receive positive and practical astrological advice

## Installation

1. **Clone or download the files** to your local machine

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application**:
   ```bash
   streamlit run astrology_chatbot.py
   ```

4. **Open your browser** and navigate to the local URL (usually `http://localhost:8501`)

## Usage

- Type your astrology-related questions in the chat input
- Ask about your zodiac sign, horoscope, or birth chart
- Get compatibility readings between signs
- Receive guidance on planetary influences

## API Key

The app uses Google Gemini API. Make sure your API key has the necessary permissions for text generation.
